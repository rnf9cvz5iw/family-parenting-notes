# 给“足”关怀，让踝不再受伤

> 更新时间：2026-09-17 (UTC+8)

点击箭头处“蓝色字”，关注我们哦！！

急性踝关节扭伤俗称崴脚，是日常生活中极为常见的损伤之一，在所有下肢外伤的人群中非常多见，约占运动损伤的25%，多发于青壮年活动量大的人群，尤其是在运动过程中更为多见。急性踝关节扭伤若不及时处理，可能会引起严重的后遗症，诸如习惯性扭伤、踝关节不稳等，早期失治误治，病情迁延不愈，可能遗留慢性疼痛、复发性肿胀、踝关节不稳，严重影响着患者的工作和生活。

**1.什么是急性踝关节扭伤?**

急性踝关节扭伤是指因步行或跑步时突然踏在不平的路面上，上下楼梯、走破路、或者踢球等不慎而导致足过度内、外翻而产生的踝部扭伤。

**2.为什么容易出现急性踝关节扭伤?**

解剖上，内踝短于外踝，外侧副韧带不如内侧副韧带坚强，内翻肌力量又大于外翻肌，当踝关节跖屈位时，距骨滑车较窄的部分进入关节窝。在不平整地面不慎摔倒，或走路疾行、跑步、跳跃时，如足部未能及时协调，踝关节容易内翻位触地，外侧副韧带遭受强大的外力牵拉出现损伤甚至断裂。当自身踝关节周围肌肉肌腱力量不足时，对关节的稳定性维持能力下降，也是造成损伤的一个因素。

**3.急性踝关节扭伤有什么症状?**

Ø 疼痛：扭伤后立即出现剧烈疼痛，尤其在活动时加剧。

Ø 肿胀：扭伤部位迅速肿胀，严重时可能导致皮肤发红、发热。

Ø 瘀血瘀斑：损伤部位可能出现片状青紫色的瘀斑或瘀点。

Ø 活动功能受限：受伤的踝关节屈伸活动不利，无法正常负重，影响行走功能。

**4.急性踝关节扭伤的现场怎么急救?**

美国骨科医师协会倡导的治疗急性踝关节扭伤的标准策略即“RICE”原则是，包括“休息(rest)、冰敷(ice)、加压包扎(compression)和抬高患肢(elevation)”

Ø 1. 制动休息：立即停止活动，避免加重损伤。

Ø 2. 冷敷：伤后6 h内，进行用冰袋或冷水毛巾敷在扭伤部位，2～3次的10 min冰敷，每次间隔20 min。

Ø 3. 加压包扎：使用弹性绷带对踝关节进行适度压迫，既能够减轻局部肿胀，又能保护性制动固定的作用，维持着关节的稳定，利于韧带的修复。

Ø 4. 抬高患者：将患肢抬高至心脏水平以上，有助于减轻肿胀。

**5.急性踝关节扭伤如何诊断?**

医生可能会通过询问病史及体检来初步判断是否有急性踝关节扭伤，进一步的确诊则可能依赖于X光检查以排除骨折的可能性;在某些情况下，MRI(磁共振成像)可以更清晰地显示软组织韧带损伤情况。

**6.急性踝关节扭伤的治疗方法如何?**

Ø 伤后48小时内，继续冷敷、制动、局部固定、抬高患肢，同时避免负重，可应用抗炎止痛药，但避免使用一些活血化瘀的药物。

Ø 伤后48小时至1周，冷敷转为热敷，促进血液循环，减轻疼痛，适当进行关节活动，防止粘连，可逐渐应用消肿止痛、活血化瘀类药物如膏药、喷雾剂、敷贴等，以促进局部肿胀的消退和疼痛的缓解。

Ø 伤后1周以后，在支具或护踝的保护下，加强踝关节周围肌肉的力量和灵活性训练，逐步恢复关节功能，也可以配合超短波、中频、超声波、中药内服外敷、针灸刺络、理筋按摩等多种方式促进病情的恢复。

**7.急性踝关节扭伤预防措施有哪些?**

 1. 充分热身：运动前进行充分的热身，提高关节的灵活性。

 2. 选择合适的运动场地和鞋具：避免在不平的地面运动，选择具有良好支撑性和缓冲性的运动鞋，上下楼梯时扶持栏杆。

 3. 注意运动姿势：运动时保持正确的姿势，避免过度扭曲踝关节。

 4. 增强踝关节稳定性：通过专项锻炼加强踝关节周围肌肉和韧带的力量。

 5. 不穿或少穿高跟鞋。 

总之，急性踝关节扭伤虽然常见，但通过正确的预防和处理方法，可以有效降低损伤的发生率，加快康复进程。一旦发生踝关节扭伤，一定要引起重视，应及时采取急救措施，并根据伤情选择合适的治疗方法，必要时及时到医院就诊，避免加重损伤。
